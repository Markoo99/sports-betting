# sports-betting
Setup and Usage
Running the Project
From the project root directory, run:
python main.py
This command runs the entire pipeline end-to-end, including data loading, preprocessing, model training, evaluation, expected value analysis, statistical significance testing, and figure generation.
All outputs are saved automatically to the results/ directory.
No additional arguments or user input are required.
Environment (Optional)
If required, a conda environment can be created using:
conda env create -f environment.yml
conda activate sports-betting
All dependencies are listed in environment.yml.
Notes
Ensure you are in the project root directory before running main.py.
The project is fully reproducible by running the command above.
