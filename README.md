# Setup and Usage

## Running the Project
From the project root directory, run:
python main.py
This command runs the entire pipeline, including data loading, preprocessing, model training, evaluation, expected value analysis, statistical significance testing, and figure generation.
All outputs are saved automatically to the results/ directory.
No additional arguments or user input are required.

## Dataset 
Below, you will find the link of the dataset that I used. To download it, simply click on the link, it will lead you to Kaggle's website. There will be a download button, press it and it will download the dataset that I used as a zip file. To use it in python, unzip it and import. 
[https://www.kaggle.com/datasets/christophertreasure/nba-odds-data]
